SortLogic Elite

Gamified Educational Lab Prototype for Sorting Algorithms

Hailey Pang | Midterm Presentation | Prof. Lama Hamandi

Problem Definition & Motivation

Why this project matters

  • Learning Gap: Students often watch sorting animations but struggle to execute algorithm logic themselves.
  • Cognitive Need: Procedural mastery requires active decision-making, not passive viewing.
  • Educational Goal: Build a system that teaches algorithm reasoning through interaction, feedback, and progression.

Core motivation: turn “seeing sorting” into “doing sorting correctly under constraints.”

Literature Review & Background

Existing tool categories

  • Passive demonstrations: e.g., Toptal sorting animations, The Sound of Sorting. Strong visualization, low user agency.
  • Interactive visualizers: e.g., SortVision, SortLGO, open-source visualizers. Adjustable controls, still mostly observational.
  • Gamified systems: e.g., SortingLab and mini-games. Better participation, often limited in algorithm breadth.

Positioning of this project

This project combines all three strengths in one system:

  • Clear visuals + pseudocode mapping
  • Structured modes and progression controls
  • Mandatory user actions (comparisons/swaps/decisions)

Research gap addressed: high-agency, multi-algorithm practice platform with feedback and mastery tracking.

Research Question & Hypothesis

Main Research Question

Can a gamified, multi-mode sorting system improve procedural understanding more effectively than observation-only tools?

Hypothesis

  • Learners who actively perform algorithm steps will demonstrate better rule-level understanding.
  • Scaffolding (tutorial/training/regular) increases retention and supports transfer from guided to independent performance.
  • Progress-based unlocking motivates sustained engagement across algorithm families.

Methodology / System Design

Design Approach

  • Modular architecture: Component-per-algorithm with shared progression utilities.
  • Pseudocode alignment: Every interaction step maps to algorithm rules.
  • Mode scaffolding: Tutorial (detailed), Training (guided), Regular (constraint-based).
  • Level progression: 3 levels per mode with unlock-by-mastery and larger arrays.

Progress & Implementation

Current Implementation Status

  • Expanded from 3 to 9 algorithms.
  • Added functional progress tracking (local persistence + real percentages).
  • Implemented mode-based scaffolding and interactive error feedback.
  • Added lecture-style onboarding in insertion tutorial mode with visual pointer mapping.

Prototype is fully usable end-to-end for interactive sorting practice.

Preliminary Results / Insights

Observed Learning Signals

  • Users can identify and correct algorithm rule violations with popup feedback.
  • Repeated guided practice improves step accuracy before entering regular mode.
  • Progress percentages and level unlocking provide visible mastery milestones.

Interpretation: The design appears to promote procedural reasoning, not just visual familiarity.
